# To-Do List Management System

This is one of my beginner-level projects built using C++.

I created a basic **To-Do List Management System** to improve my understanding of file handling, functions, and project organization in C++.

This is a self-coded project developed mainly by me, with a little assistance from AI tools for learning purposes. I understood the concepts and implemented the logic by myself.

## Features

- Add tasks
- Delete specific tasks
- View all tasks
- View a specific task
- Remove all tasks
- Store tasks using file handling

## Concepts Learned

- File Handling
- Functions and Function Calling
- Working with Multiple Operations
- Basic Project Structure
- Console-Based Application Development

## About the Project

This project helped me understand how real applications store and manage data using files.

I also learned how to:

- Read and write data from files
- Manage user input
- Organize logic into reusable functions
- Perform task-based operations in a console application

## Tech Used

- C++
- File Handling
- Basic Functional Programming Concepts

## Goal

The goal of this project was to strengthen my fundamentals in C++ by building a practical console-based application.

Through this project, I gained confidence in handling files, creating reusable functions, and managing application flow.
